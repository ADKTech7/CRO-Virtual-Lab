# CRO Virtual Lab – Version 4

A proper academic Virtual Lab-style experiment built from the previous CRO project.

## Included
- Home, Aim, Theory, Prerequisites, Learning Objectives and Apparatus
- Step-by-step experiment procedure
- Dual-channel virtual CRO
- Function generator controls
- Virtual CH1/CH2 probes
- VOLTS/DIV, TIME/DIV, coupling and trigger mode
- Waveform observation
- X-Y/Lissajous mode
- Observation and calculation entry
- Automatic observation checking
- Assessment and pass/fail result
- GitHub Pages-compatible static deployment

## Deploy
Upload `index.html` and `README.md` to a GitHub repository and enable:
Settings → Pages → Deploy from branch → main → /root.

This is an independent educational implementation. For institutional submission, adapt the content and metadata to the required Virtual Labs/college template and accessibility standards.
